# Scrum Board - Управление задачами

## Краткое описание
Scrum Board - это приложение для визуального управления задачами по методологии Scrum. Позволяет создавать проекты, управлять задачами в различных статусах (Назначено, В процессе, Блокировано, Готово), назначать разработчиков и отслеживать прогресс работы.

## Требования
- C++ компилятор с поддержкой C++11
- SFML 2.5+
- JSON для хранения данных (nlohmann/json)

## Установка и запуск
1. Клонировать репозиторий
2. Установить зависимости (SFML)
3. Скомпилировать проект с помощью CMake
4. Запустить исполняемый файл

## Структура данных
Данные хранятся в JSON формате:
- `developers.json` - информация о разработчиках
- `project_scrumboard.json` - данные о проектах и задачах

## Основные классы
- `ScrumBoard` - главный класс приложения
- `Task` - представление задачи для интерфейса
- `Tasks` -  информация о задачах
- `Developer` - информация о разработчике
- `Project` - управление проектами

## Управление
- **Вход/Выход**: кнопка "Войти"/имя пользователя
- **Проекты**: кнопка "Проекты" для выбора активного проекта
- **Добавление задач**: кнопка "Добавить задачу"
- **Редактирование**: кнопка "Редактировать" для изменения задач
- **Перетаскивание**: захватите задачу для перемещения между секциями
